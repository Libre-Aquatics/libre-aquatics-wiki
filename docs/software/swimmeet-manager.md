This article is a stub. SwimMeet Manager was a Windows meet-management program from
Hy-Point Software, advertised in the swimming press from September 2000 into 2001 for
leagues, high schools and age-group clubs, and sold in part on being fully compliant with
the [SDIF](sdif.md) data exchange standard.

The compliance claim is the company's own, and it is useful chiefly as evidence that the
published standard was a competitive argument around 2000; see the
[software overview](index.md) for what this section covers.
