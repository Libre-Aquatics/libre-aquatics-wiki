This article is a stub. ACTIVEWorks Swim Manager is a web product from
[The Active Network](../vendors/active-network.md) for club and meet administration,
documented in the same knowledge base as the Hy-Tek programs, which produces a meet entry
file as a zip archive containing an [HY3](hy3.md).

It shows that Hy-Tek's file formats remain the current interchange rather than a legacy of
the desktop products, since a club using the web product still hands its meet host the same
kind of file; see the [software overview](index.md) for what this section covers.
