This article is a stub. TOP-8 is a [Swiss Timing](../vendors/swiss-timing.md) program for the
[PowerTime](../equipment/swimming/timers/powertime.md) and
[PowerTime II](../equipment/swimming/timers/powertime-ii.md) timers that records finishes for up
to eight lanes, one judge's pushbutton per lane, or for a single finish line by bib number
(user manual `3462.511.02`).

See the [software overview](index.md) for the other programs this wiki covers.
