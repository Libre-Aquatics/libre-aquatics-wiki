This article is a stub. The Standalone Template Editor, part number `R-470-121`, is the
[DisplayLink Plus](displaylink-plus.md) template designer packaged as a separate application,
recorded in the DisplayLink Plus release notes as created for v4.3.14 in March 2020 and sold
separately from the main program.

See the [DisplayLink Plus](displaylink-plus.md) article for what a template is and how the
editor is used.
