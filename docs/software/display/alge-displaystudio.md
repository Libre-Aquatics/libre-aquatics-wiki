This article is a stub. DisplayStudio is the [ALGE-Timing](../../vendors/alge-timing.md) Windows
program used to design text, image and animation lists for the
[D-RTNM](../../equipment/common/scoreboard/alge-d-rtnm.md) and other ALGE matrix display boards, set
their network addresses and load the lists into them.

See the [software overview](../index.md) for the other programs and interchange methods this wiki
covers.
