This article is a stub. Venus is the Daktronics software that controls its scoreboards and
matrix displays, in versions that include Venus 1500 and the Windows-based Venus 7000, and it
accepts live timing data in the [ERTD](ertd.md) format from consoles such as the Swiss Timing
[ARES 21](../equipment/swimming/timers/ares-21.md).

See the [software overview](index.md) for the other programs the wiki covers.
