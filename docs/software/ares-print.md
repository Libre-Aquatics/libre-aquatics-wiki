This article is a stub. ARES-Print is the Swiss Timing program that prints race results for the
[ARES 21](../equipment/swimming/timers/ares-21.md) system, receiving each finished race from ARES
Swimming over a Windows DDE link as the default End of race action.

See the [software overview](index.md) for the other programs the wiki covers.
