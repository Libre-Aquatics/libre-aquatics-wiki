This article is a stub. OmniSport Pro Synchro is a [Daktronics](../vendors/daktronics.md)
Windows program, first released in 2007, that scores synchronized swimming through an
[OmniSport 2000](../equipment/swimming/timers/omnisport-2000.md) timing console, which cannot
score the sport by itself, taking marks from 2 to 18 [RC-100](../equipment/diving/rc-100.md) or
[JC-100](../equipment/diving/jc-100.md) judge consoles.

It is a companion to [OmniSport Pro Diving](omnisport-pro-diving.md), the diving program built on
the same console.
