This article is a stub. SST App Server, also called the SST Application Server, is a
[Superior Swim Timing](../vendors/superior-swim-timing.md) program that receives the scoreboard
feed from the timing computer and sends it to phones and tablets running the
[SST Scoreboard App](sst-scoreboard-app.md).

See the [SST timing software](sst-timing-software.md) article for the other scoreboard outputs.
