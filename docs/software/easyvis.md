This article is a stub. EasyVis is a display program by Björn Stickan that works with
[EasyWk](easywk.md) to show an announcer screen, award ceremony slides and live timing data from
Omega or Colorado consoles on a projector; version 1.06 dates from October 2024.

See the [software overview](index.md) for the other programs the wiki covers.
