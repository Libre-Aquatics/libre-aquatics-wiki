This article is a stub. TouchPad is a meet-management program from
[TeamUnify](teamunify.md) that the 2019 manual for the
[SST timing software](sst-timing-software.md) describes connecting through a shared results folder.

See the [software overview](index.md) for the other programs this wiki covers.
