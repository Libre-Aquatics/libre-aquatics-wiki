This article is a stub. SplashMe is a mobile application for iOS and Android that shows live
start lists and results from meets run on [Splash Meet Manager](splash-meet-manager.md), for
meets registered in the [Swimrankings](swimrankings.md) calendar.

It fills the same role for Splash meets that [Meet Mobile](meet-mobile.md) fills for Hy-Tek
ones; see the [software overview](index.md) for what this section covers.
