This article is a stub. Swimrankings is a swimming results and rankings database owned by
Christian Kaufmann, which issues the worldwide meet, club and athlete identifiers that
[Lenex](lenex.md) files carry and hosts the format's documentation.

Its wiki is also the documentation site for [Splash Meet Manager](splash-meet-manager.md);
see the [software overview](index.md) for what this section covers.
