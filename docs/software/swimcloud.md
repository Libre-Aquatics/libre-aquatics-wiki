This article is a stub. Swimcloud is a swimming results and rankings website that publishes
meet results sent to it as Hy-Tek export zips, [CL2](cl2.md) or [SDIF](sdif.md) files, and
Hy-Tek Meet Manager has an export command that uploads results to it directly.[^upload][^mm]

It also accepts [Lenex](lenex.md) files; see the [software overview](index.md) for what this
section covers.

[^upload]: [Swimcloud, Uploading Meet Results](https://support.swimcloud.com/hc/en-us/articles/7159725331347-Uploading-Meet-Results) (support article).
[^mm]: [HY-TEK, Export Results to Swimcloud](https://hytek.active.com/user_guides_html/swmm7/export-results-to-swimcloud.htm) (Meet Manager 7 user guide).
