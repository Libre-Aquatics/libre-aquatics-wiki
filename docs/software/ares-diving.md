This article is a stub. ARES Diving, part number `3330.633`, is the Swiss Timing program for
scoring diving and synchronized diving on the [ARES 21](../equipment/swimming/timers/ares-21.md)
system, taking judges' awards through the interface box's serial and judging-console inputs.

See the [software overview](index.md) for the other programs the wiki covers.
