This article is a stub. SwimTime is the [ALGE-Timing](../vendors/alge-timing.md) Windows program
that operates the [TM-SWIM](../equipment/swimming/timers/alge-tm-swim.md) timing console and
exchanges start lists and results with meet-management programs.

See the [software overview](index.md) for the other programs and interchange methods this wiki
covers.
