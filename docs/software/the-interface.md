This article is a stub. The Interface was a Hy-Tek package of a disk and a cable, announced
in August 1988, that connected [Meet Manager](hy-tek-meet-manager.md) to timing consoles
made by Omega, Daktronics, [Kyrotech](../vendors/kyrotech.md),
[Incomar](../vendors/incomar.md) and
[Colorado Time Systems](../vendors/colorado-time-systems.md) so that times and splits
reached the program directly.

It was sold separately from Meet Manager, and the console interfaces that replaced it are
now licence options within the program itself; see the
[software overview](index.md) for what this section covers.
