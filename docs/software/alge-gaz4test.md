This article is a stub. GAZ4Test is an [ALGE-Timing](../vendors/alge-timing.md) PC program for
sending data to [GAZ4](../equipment/common/scoreboard/alge-gaz4.md) and later display boards,
offered from 2001 and updated to 2016 with network output and
[D-LINE](../equipment/common/scoreboard/alge-d-line.md) support.

See the [software overview](index.md) for the other programs and interchange methods this wiki
covers.
