This article is a stub. WinSwim is a Windows swimming software package that moves meet
entries and results between teams and between programs using [SDIF](sdif.md), the published
United States Swimming interchange format.

Its site is the source of [SDIFCheck](sdifcheck.md), the validation utility that SDIF's
own lack of a checksum makes necessary; see the [software overview](index.md) for what this
section covers.
