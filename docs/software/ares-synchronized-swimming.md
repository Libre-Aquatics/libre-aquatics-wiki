This article is a stub. ARES Synchronized Swimming, part number `3330.634`, is the Swiss Timing
program for scoring synchronized swimming, now called artistic swimming, on the
[ARES 21](../equipment/swimming/timers/ares-21.md) system.

See the [software overview](index.md) for the other programs the wiki covers.
