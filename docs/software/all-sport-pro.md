This article is a stub. All Sport Pro is Daktronics' scoreboard control software that runs in a
web browser on a laptop or tablet, supported by the
[All Sport 5000](../equipment/common/scoreboard-control/all-sport-5000.md) console's firmware
from 2019 and extended in September 2025 to select fixed-digit scoreboards.

See the [software overview](index.md) for the shared background on aquatics software.
