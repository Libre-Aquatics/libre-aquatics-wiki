This article is a stub. SWIM-Manager is the meet-management program of
[ALGE-Timing](../vendors/alge-timing.md)'s free Windows package for the
[SWIM 2000](../equipment/swimming/timers/alge-swim-2000.md), which also includes the Timing-Manager
and Simple-Timing programs that operate the system's [SWC](../equipment/swimming/timers/alge-swc.md)
controller.

See the [software overview](index.md) for the other programs and interchange methods this wiki
covers.
