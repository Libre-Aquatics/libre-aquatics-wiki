This article is a stub. i-Judge is an Integrated Sports Systems program in which each diving or
artistic swimming judge enters awards on a Windows computer or tablet, sending them over a network
to the scoring computer running [DIV Scoring Manager](div-scoring-manager.md),
[SWA Scoring Manager](swa-scoring-manager.md) or ISS's own scoring software.

See the [software overview](index.md) for the other programs the wiki covers.
