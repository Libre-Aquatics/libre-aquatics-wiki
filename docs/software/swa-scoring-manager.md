This article is a stub. SWA Scoring Manager is a Windows program for running artistic swimming
competitions, sold by Swiss Timing and written with
[Integrated Sports Systems](../vendors/integrated-sports-systems.md), which handles registration,
draws, judging panels and Coach Cards, takes scores from [i-Judge](i-judge.md) or Omega keypads,
and has been updated through 2026 for each change in World Aquatics scoring rules.

It is built the same way as its diving counterpart, [DIV Scoring Manager](div-scoring-manager.md);
see the [software overview](index.md) for the other programs the wiki covers.
