This article is a stub. OmniSport Pro Swimming is a [Daktronics](../vendors/daktronics.md)
Windows program, first released in October 2002, that runs swim races through an
[OmniSport 2000](../equipment/swimming/timers/omnisport-2000.md) timing console over a serial or
Ethernet link and collects touchpad, button, relay exchange and reaction times.

Daktronics no longer sells it; see [OmniSport Pro Synchro](omnisport-pro-synchro.md) and
[OmniSport Pro Diving](omnisport-pro-diving.md) for the sibling programs on the same console.
