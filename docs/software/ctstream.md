This article is a stub. CTStream is video overlay software that
[DisplayLink Plus](displaylink-plus.md) gained a connection to in version 4.5.0 in April
2022, according to that program's release notes, which also record the connection being
restored in October 2024.

Colorado Time Systems has published nothing else about it, and its relationship to
[CTS AquaSync](cts-aquasync.md), which performs the same role, is undocumented.
