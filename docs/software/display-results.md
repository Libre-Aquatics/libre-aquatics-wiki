This article is a stub. Display Results is an Integrated Sports Systems program, also supplied
in a Swiss Timing edition, that reads the standings written by
[DIV Scoring Manager](div-scoring-manager.md) or [SWA Scoring Manager](swa-scoring-manager.md)
and shows the event on projectors, televisions or LED walls and on live Internet results pages.

See the [software overview](index.md) for the other programs the wiki covers.
