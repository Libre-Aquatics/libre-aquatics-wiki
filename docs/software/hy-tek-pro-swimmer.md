This article is a stub. Pro SWIMMER was a Hy-Tek program for Palm OS handhelds, released in
the early 2000s, that recorded hand times, splits and stroke rates on deck and synchronised
them with a club's [Team Manager](hy-tek-team-manager.md) database.

Hy-Tek no longer sells or supports it, although Team Manager 8.0 can still import results
from it; see the [software overview](index.md) for what this section covers.
