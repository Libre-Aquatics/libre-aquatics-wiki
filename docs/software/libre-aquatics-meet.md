Libre Aquatics Meet is a planned open-source meet-management application for aquatic
sports, the software that builds a meet's events and heats, seeds entries, records
results from the timing system, scores the competition, and produces heat sheets and
results.

It is part of the [Libre Aquatics project](../about/index.md) alongside
[Libre Aquatics Team](libre-aquatics-team.md) and this reference, [Libre Aquatics Wiki](../index.md).

## Goals

- Open source and free to run at any facility.
- Interoperable with common timing consoles and entry/result file formats.
- A modern, approachable interface for meet operators and volunteers.
