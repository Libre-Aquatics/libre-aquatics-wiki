This article is a stub. DisplayLink is the Colorado Time Systems Windows software that drove
the company's matrix display systems before [DisplayLink Plus](displaylink-plus.md). It ran
under Windows NT 4.0 or Windows 2000 and split its work across a Designer window, a separate
Template Editor application, and two data modules: AquaLink for the aquatic sports and
GameLink for team sports.

Its templates cannot be opened in DisplayLink Plus, which replaced the suite with a single
program.
