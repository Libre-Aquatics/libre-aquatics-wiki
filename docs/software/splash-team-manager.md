This article is a stub. Splash Team Manager is the club-side program from
[Splash Software](../vendors/splash-software.md), the counterpart to
[Splash Meet Manager](splash-meet-manager.md), which keeps a club's members, entries and
results and was still receiving updates in 2026.

It has no connection to [Hy-Tek Team Manager](hy-tek-team-manager.md) beyond the name; see
the [software overview](index.md) for what this section covers.
