This article is a stub. ISS MMS Artistic Swimming is the Integrated Sports Systems program for
running and scoring artistic swimming meets, at version 6.8.0 for the 2026 World Aquatics rules,
of which Swiss Timing sells an edition as [SWA Scoring Manager](swa-scoring-manager.md).

See the [software overview](index.md) for the other programs the wiki covers.
