This article is a stub. EasyAnzeige is a program by Björn Stickan, launched in April 2025, that
drives a video scoreboard as a second HDMI screen, showing start lists, live races and results
from [EasyWk](easywk.md) and the timing system.

See the [software overview](index.md) for the other programs the wiki covers.
