This article is a stub. EasyFW is a stand-alone program by Björn Stickan for timing open water
swims on a PC, which records finish times against start numbers and exports them to
[EasyWk](easywk.md); version 1.03 dates from December 2019.

See the [software overview](index.md) for the other programs the wiki covers.
