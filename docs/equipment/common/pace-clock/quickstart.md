This article is a stub. QuickStart is a Colorado Time Systems portable LED display that counts
as a plain pace clock on its own and, with a CTS pushbutton, start system, relay judging
platform or touchpad plugged in, times start reactions, break-outs, relay exchanges and
breaststroke and butterfly turns, showing each result in hundredths.

See the [pace clocks overview](index.md) for the shared background, and the
[Ultimate Pace Clock](ultimate-pace-clock.md), whose portable displays did the same job.
