This article is a stub. The D-RTNM is an [ALGE-Timing](../../../vendors/alge-timing.md) matrix
LED scoreboard that shows event names, heat numbers and messages, enabled from the network
settings of [SwimTime](../../../software/swimtime.md).

See the [scoreboards overview](index.md) for the shared background on scoreboards.
