This article is a stub. The `WP-2103` is a [Daktronics](../../../vendors/daktronics.md)
portable, battery-powered water polo display, about 22 in (0.56 m) square, that shows game time
and shot time and is run from an [All Sport 5000](../scoreboard-control/all-sport-5000.md).

Daktronics lists it beside the [WP-2101](wp-2101.md) scoreboard; see the
[scoreboards overview](index.md) for the shared background on scoreboards.
