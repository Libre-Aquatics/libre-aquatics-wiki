This article is a stub. The Myriad is a Colorado Time Systems multi-color LED matrix
display, driven from a dedicated computer running
[DisplayLink](../../../software/displaylink.md) software and covered together with the
[Mercury16](mercury16.md) by one CTS manual, F853.

See the [scoreboards overview](index.md) for the shared background that applies to every
matrix display.
