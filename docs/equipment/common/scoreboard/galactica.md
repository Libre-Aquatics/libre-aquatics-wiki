This article is a stub. Galactica is a Swiss Timing alphanumeric scoreboard system, one of the
two scoreboard types in the [ARES 21](../../swimming/timers/ares-21.md) software and later
served by the Swiss Timing alphanumeric output of
[Quantum Aquatics](../../swimming/timers/quantum.md), which takes start lists from the timer and
shows the competitors' names.

See the [scoreboards overview](index.md) for the shared background.
