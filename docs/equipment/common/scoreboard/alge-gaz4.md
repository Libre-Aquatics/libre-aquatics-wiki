This article is a stub. The `GAZ4` is an [ALGE-Timing](../../../vendors/alge-timing.md) numeric
display board with bistable electromagnetic seven-segment digits 15, 25 or 45 cm high, sold with
the [SWIM 2000](../../swimming/timers/alge-swim-2000.md) swimming system.
