This article is a stub. The All Sport 5500 series is a Daktronics keyboard console for the
company's ColorSmart colour-changing scoreboards, with software first released in January 2007
and production listed as 2006 to 2024, built alongside the
[All Sport 5000](all-sport-5000.md), which can run a ColorSmart board only in red.

See the [scoreboard control overview](index.md) for the shared background on scoreboard
controllers.
