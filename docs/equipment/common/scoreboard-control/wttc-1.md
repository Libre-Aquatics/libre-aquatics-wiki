This article is a stub. The WTTC-1 is a Colorado Time Systems tabletop wireless controller
for multisport scoreboards, which runs a board's scoring and clocks for one sport at a time
from a keypad at the officials' table.

See the [scoreboard control overview](index.md) for the shared background, and the
[scoreboards overview](../scoreboard/index.md) for the boards it drives.
