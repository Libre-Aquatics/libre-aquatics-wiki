This article is a stub. Colorado Time Systems run-stop-reset units, the single-button `RSR-1`
and the two-button water polo `RSR-3`, are hand switches that plug into a
[WTTC-1](wttc-1.md) so that a second or third timekeeper can run the game clock and reset the
shot clock.

See the [WTTC-1](wttc-1.md) article for how the controller assigns the clocks to each unit, and
the [scoreboard control overview](index.md) for the shared background.
