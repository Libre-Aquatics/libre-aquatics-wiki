This article is a stub. The Daktronics main clock start/stop/horn switch (`0A-1166-0003`) is a
handheld rocker switch with a horn button that plugs into jack J4 of an
[All Sport 5000](all-sport-5000.md) so a second official can run the game clock and sound the
horn away from the console.

See the [scoreboard control overview](index.md) for the shared background on scoreboard
controllers.
