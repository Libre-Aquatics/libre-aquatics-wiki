This article is a stub. The SST scoreboard adapter is a USB-to-serial adapter from
[Superior Swim Timing](../../../vendors/superior-swim-timing.md) that connects earlier
[SST timers](../../swimming/timers/sst-timer.md) to a serial scoreboard.

See the [scoreboard control overview](index.md) for the shared background on driving a board.
