This article is a stub. The All Sport 1600 series is a Daktronics scoreboard control console,
first released in December 2000, that Daktronics lists beside the larger
[All Sport 5000](all-sport-5000.md) as a controller for the [PC-2001](../pace-clock/pc-2001.md)
pace clock and the [TI-2101](../pace-clock/ti-2101.md) timing display.

See the [scoreboard control overview](index.md) for the shared background on scoreboard
controllers.
