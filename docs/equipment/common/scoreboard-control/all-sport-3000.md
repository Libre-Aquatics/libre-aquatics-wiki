This article is a stub. The All Sport 3000 series is a Daktronics scoreboard console made from
2000 to 2008 that shared its scoreboard wiring drawings with the
[All Sport 5000](all-sport-5000.md) and, like it, could carry an optional radio.

See the [scoreboard control overview](index.md) for the shared background on scoreboard
controllers.
