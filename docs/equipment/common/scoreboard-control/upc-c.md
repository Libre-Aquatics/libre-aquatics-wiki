This article is a stub. The pace clock controller, `UPC-C`, is a Colorado Time Systems
console that stores training workouts and runs them on a CTS pace clock or scoreboard
without a timing console in the loop.

See the [scoreboard control overview](index.md) for the shared background, and the
[scoreboards overview](../scoreboard/index.md) for the boards it drives.
