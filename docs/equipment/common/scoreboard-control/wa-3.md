This article is a stub. The WA-3 is the Colorado Time Systems 2.4 GHz wireless scoreboard
adapter, `WA-3`, which carries scoreboard data by radio from a timing console, a laptop or
a [DisplayLink Plus](../../../software/displaylink-plus.md) computer to a CTS LED board up
to 1000 ft (100 m) away. Adapters are used in pairs, one at each end, unless the board has
2.4 GHz reception of its own.

See the [scoreboard control overview](index.md) for the shared background on how data
reaches a board.
