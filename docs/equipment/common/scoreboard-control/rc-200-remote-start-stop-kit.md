This article is a stub. The Daktronics RC-200 remote start/stop kit (`0A-1110-0074`) pairs an
[RC-200](../../diving/rc-200.md) handheld with its own outdoor
[base station](../../diving/rc-200-base-station.md) and a junction box on jack J4 or J7 of an
All Sport console such as the [All Sport 5000](all-sport-5000.md), so the game clock or a
delay-of-game clock can be started, stopped and reset or horned by radio.

See the [scoreboard control overview](index.md) for the shared background on scoreboard
controllers.
