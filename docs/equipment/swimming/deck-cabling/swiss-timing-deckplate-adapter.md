This article is a stub. The Swiss Timing deckplate adapter (`3274.049`) plugs into a
[Swiss Timing deck plate](swiss-timing-deck-plate.md) used as a start plate and provides Tuchel
sockets, one marked START, so that a [StartTime](../starter/starttime-v.md) start system can be
connected for the start signal and loudspeakers.

See the [deck cabling overview](index.md) for the shared background on fixed in-deck wiring.
