This article is a stub. The Quantum start cable, Swiss Timing part `1865.010`, is the 4-pin
Tuchel cable that carries the start and ready signals from an [ODB10-SW](odb10-sw.md)
distribution box to a START input on a [Quantum Aquatics](../timers/quantum.md) timer.

See the [deck cabling overview](index.md) for the shared background on fixed in-deck wiring.
