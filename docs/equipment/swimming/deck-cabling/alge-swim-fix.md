This article is a stub. SWIM-FIX is the box that ALGE-Timing's 1997 under-deck drawing for the
[Timer S4](../timers/alge-timer-s4.md) swimming system places between a mains supply and the eight
starting blocks; the guide's text does not describe it.

See the [deck-cabling overview](index.md) for the shared background on lane wiring.
