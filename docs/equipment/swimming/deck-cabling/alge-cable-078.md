This article is a stub. The `078` is the [ALGE-Timing](../../../vendors/alge-timing.md) 5-core
cable that joins an [S4-SWIM](alge-s4-swim.md) lane box to each [FIN1](alge-fin1.md) finish
adapter, supplied in four lengths so that the shortest serves the nearest pair of lanes.

See the [deck-cabling overview](index.md) for the shared background on lane wiring.
