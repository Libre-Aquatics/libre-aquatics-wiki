This article is a stub. ALGE-Timing sells deck wiring for the
[TM-SWIM](../timers/alge-tm-swim.md) as `SWCBL` terminal sets and `SWSPA` speaker sets, made up
of numbered `200-xx` and `201-xx` cables, with `199-xx` cables and `KT` reels for the start
line.

See the [deck-cabling overview](index.md) for the shared background on lane wiring.
