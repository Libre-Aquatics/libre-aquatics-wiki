This article is a stub. The Swiss Timing swimming harness (`3361.611`) is a chain of nine boxes,
one for the start and eight for lane pushbuttons, that lets a
[PowerTime II](../timers/powertime-ii.md) or the earlier [PowerTime](../timers/powertime.md)
time an eight-lane swimming race with the TOP-8 program.

See the [deck cabling overview](index.md) for the shared background that applies to every
deck cabling system.
