This article is a stub. The `SWR1` is an [ALGE-Timing](../../../vendors/alge-timing.md)
stainless-steel relay pad with a quartz-sand top that screws onto an existing starting block, named
on ALGE's 2001 SWIM 2000 page before the strap-on [SWR 2](alge-swr2.md).

See the [relay take-off platforms overview](index.md) for the shared background that applies to
every relay take-off device.
