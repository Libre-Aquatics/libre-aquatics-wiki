This article is a stub. The `SWR 2` is an [ALGE-Timing](../../../vendors/alge-timing.md)
stainless-steel relay take-off pad that fits onto an existing starting block, sold with the
[SWIM 2000](../../swimming/timers/alge-swim-2000.md) system and still in ALGE's 2013 catalogue.

See the [relay take-off platforms overview](index.md) for the shared background that applies to
every relay take-off device.
