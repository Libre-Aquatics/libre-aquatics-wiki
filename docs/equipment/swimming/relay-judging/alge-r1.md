This article is a stub. The `R1` appears only as "False Start Detector R1" in the legend of
ALGE-Timing's 1994 wiring drawing for a [Timer S4](../timers/alge-timer-s4.md) swimming system with
a false-start system, and the accompanying guide does not say what it detects.

See the [relay take-off platforms overview](index.md) for the shared background that applies to
relay take-off judging.
