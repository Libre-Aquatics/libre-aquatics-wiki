This article is a stub. The Velocity is a starting platform series made by
[S.R. Smith](../../../vendors/s-r-smith.md), sold as `VELO-TS-TA` and related models, whose track
start wedge folds away under the fiberglass footboard and which S.R. Smith advertises as compatible
with Colorado Time Systems and Daktronics timing.

See the [starting blocks overview](index.md) for the shared background that applies to every
starting block.
