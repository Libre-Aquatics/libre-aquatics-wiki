This article is a stub. The Colorado Block is a starting block that Colorado Time Systems
described in 2004 as a [Paragon Aquatics](../../../vendors/paragon-aquatics.md) Track Start
Competitor platform fitted with a CTS [relay take-off platform](../relay-judging/cts.md) with
speedlights, an under-block speaker and a
[QuickConnect](../deck-cabling/cts-quickconnect-deck-plate.md) connection hub.

See the [starting blocks overview](index.md) for the shared background that applies to every
starting block.
