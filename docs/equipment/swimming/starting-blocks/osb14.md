This article is a stub. The OSB14 is a Swiss Timing swimming starting block with an adjustable
footrest, made with or without relay break detection, whose base sits 238 mm back from the pool
edge over a [Swiss Timing deck plate](../deck-cabling/swiss-timing-deck-plate.md) when the pool
is wired in the deck.

See the [starting blocks overview](index.md) for the shared background on starting blocks.
