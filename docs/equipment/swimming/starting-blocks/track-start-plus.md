This article is a stub. Track Start PLUS+ is a set of [Paragon Aquatics](../../../vendors/paragon-aquatics.md)
kits that add an adjustable backplate (`27500`) and side hand grips (`27501`) to Track Start
platforms, with an STS version that slides a backplate across standard-size tops.

See the [starting blocks overview](index.md) for the shared background that applies to every
starting block.
