This article is a stub. The `SO 2` is an [ALGE-Timing](../../../vendors/alge-timing.md)
stainless-steel starting block with a built-in relay take-off sensor, made for the
[SWIM 2000](../timers/alge-swim-2000.md) system in a low version and a high `SO 2-EX` version.

See the [starting blocks overview](index.md) for the shared background that applies to every
starting block.
