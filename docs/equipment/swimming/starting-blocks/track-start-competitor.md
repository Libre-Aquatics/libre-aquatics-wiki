This article is a stub. The Track Start Competitor is a Paragon Aquatics starting platform with a
stainless steel twin-leg frame and a 24 × 32 in polypropylene track start top, made in a
side-step version and a long reach rear-mount version for wide overflow gutters, and is the base
of the [Colorado Block](colorado-block.md).

See the [starting blocks overview](index.md) for the shared background that applies to every
starting block.
