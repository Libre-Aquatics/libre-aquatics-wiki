This article is a stub. The `SO5` is an [ALGE-Timing](../../../vendors/alge-timing.md)
polyethylene starting platform with a six-position footrest and an integrated sensor for
reaction and relay take-off times.

See the [starting blocks overview](index.md) for the shared background that applies to every
starting block.
