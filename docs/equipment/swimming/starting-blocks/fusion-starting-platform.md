This article is a stub. The Fusion Starting Platform (Spectrum part `57281`) is a single-post
starting block made by [Spectrum Aquatics](../../../vendors/spectrum-aquatics.md) with a Colorado
Time Systems [relay take-off platform](../relay-judging/cts.md) built into its top, listed in
CTS's 2015 catalog.

See the [starting blocks overview](index.md) for the shared background that applies to every
starting block.
