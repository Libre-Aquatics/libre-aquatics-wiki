This article is a stub. Quickset is a [Paragon Aquatics](../../../vendors/paragon-aquatics.md)
starting platform and anchor system, introduced in 1986, in which the platform post drops into a
covered deck socket and is locked and released by hand without tools (current anchor `23302`).

See the [starting blocks overview](index.md) for the shared background that applies to every
starting block.
