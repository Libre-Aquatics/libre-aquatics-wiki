This article is a stub. The Colorado Time Systems Dolphin Wireless Stopwatch Timing
System is a 2.4 GHz wireless timing system in which each lane timer holds a handheld
stopwatch (`R-1004-0506`) that reports its times by radio to a base unit
(`R-1004-0505`) on the meet computer, with a
[Dolphin Starter Unit](../starter/dolphin-starter-unit.md) available to start every
watch together.

See the [semi-automatic timing overview](index.md) for the shared background that
applies to every semi-automatic timing system.
