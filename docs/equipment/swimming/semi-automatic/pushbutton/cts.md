The Colorado Time Systems pushbutton is the hand-held backup timing button used with
[Colorado Time Systems](../../../../vendors/colorado-time-systems.md) (CTS)
swim-timing systems. A timer standing behind a lane holds the button and presses it as
the swimmer touches the wall, which sends a stop signal to that lane's clock on the
[timing console](../../timers/index.md). It is the secondary, human-operated input that
backs up the [touchpad](../../touchpad/aquagrip.md) at each lane. CTS sells the current
model as the PB-6, a button on a six-foot cord; the shop listing also calls it a swim
timing "pickle."[^ctspb][^ctsshop][^poolweb]

## Role in the timing system

The [pushbuttons overview](index.md) covers the shared background that applies to every
backup button: the layered primary/secondary/tertiary timing structure, the
governing-body rules that require independent backup, and how button times resolve into
an official time. In a CTS installation the button is that secondary layer. In fully
automatic officiating the [touchpad](../../touchpad/aquagrip.md) records the official time
and the buttons stand ready in case it fails; in semi-automatic operation the buttons
themselves are the timing input, started by the electronic start and stopped by the
timer's press.[^usaswim]

Each lane can carry one, two, or three backup buttons, designated A, B, and C, each
plugged into its own backup connector so the buttons and the pad are read
independently.[^tdp][^poolweb] The timer watches the swimmer into the wall and presses
the button at the touch; the console records each button press as a separate time
alongside the pad time.

## Design and connection

The pushbutton is a sealed momentary switch in a hand-held housing on a flexible cord
that ends in a banana plug. It plugs into the same lane connection points as the
touchpad: a CTS Titanium Deck Plate (TDP) or an on-deck cable harness. CTS presents the
deck plate as the thing that makes plug-in connection possible at all, for the touchpad,
the A/B/C backup pushbuttons, [relay judging](../../relay-judging/index.md), the start
speakers and the lane's start signal alike, and says the
plate's titanium jacks and domed top protect the banana plugs from the corrosion that
pool chemicals and standing water cause.[^tdp] On a cable-harness installation the
primary harness carries the touchpad and one pushbutton per lane, with backup harnesses
adding the further button inputs.[^harness]

The button works with the CTS touchpad lane systems and, per the vendor and resellers,
with the Championship and Infinity start systems; it can also be used on its own through
a cable harness where no touchpads are installed.[^ctsshop][^poolweb] The signal it
carries is the low-voltage lane input the timer reads and isolates, the same electrical
path used by the pad.[^tdp] CTS also offers a wireless alternative to wired buttons, the
[Dolphin system](../dolphin.md), in which each lane's timer holds a wireless
stopwatch rather than a plugged-in button.[^dolphin]

## Care and maintenance

The banana plug is the part that fails, because pool water corrodes the contact. CTS
treats plug care as routine maintenance across its lane hardware: the two-pronged banana
plug is kept clean and, when badly corroded, replaced with the same part used on the
touchpads (CTS `R-025-045`).[^f147] The CTS touchpad test meter (`TPM-D`) checks a
pushbutton along with the pad, cable harness, and deck plates, so a suspect button can
be verified before a session rather than during a race.[^f147]
