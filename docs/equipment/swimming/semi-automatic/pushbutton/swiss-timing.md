This article is a stub. The Omega OIT3 (`2872.003`) is a Swiss Timing hand-held judge's
pushbutton with a normally open contact, supplied one per lane with each
[Quantum Mobile Harness](../../deck-cabling/quantum-mobile-harness.md) set and plugged into the
red sockets of the harness modules.

See the [pushbuttons overview](index.md) for the shared background that applies to every
pushbutton.
