This article is a stub. The OBL1 is the first Omega Backstroke Ledge made by Swiss Timing, named
in the [OSB14](../starting-blocks/osb14.md) manual as mounting on that block's platform and
followed by the [OBL2 Pro](swiss-timing.md).

See the [backstroke start devices overview](index.md) for the shared background that applies to
every backstroke start device.
