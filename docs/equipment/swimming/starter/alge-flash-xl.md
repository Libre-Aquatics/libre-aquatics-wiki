This article is a stub. The `FLASH XL` is an [ALGE-Timing](../../../vendors/alge-timing.md) LED
flash that gives a visual start signal, powered over a `199-xx` cable from a
[TM-SWIM](../timers/alge-tm-swim.md) or by its own batteries.

See the [start-systems overview](index.md) for the shared background that applies to every start
system.
