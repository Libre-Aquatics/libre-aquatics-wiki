This article is a stub. The `SA1` is the [ALGE-Timing](../../../vendors/alge-timing.md) start unit
of the [Timer S4](../timers/alge-timer-s4.md) swimming system, which starts the timer and sounds up
to four [LK1](../external-speaker/alge-lk1.md) horns from one handswitch, and sends a false-start
signal on a second press within five seconds.

See the [start-systems overview](index.md) for the shared background that applies to every start
system.
