This article is a stub. The `SU2` is the [ALGE-Timing](../../../vendors/alge-timing.md) start unit
with a built-in microphone and start push button that ALGE's 2013 swimming catalogue shows, and the
[SU3](alge-su3.md) had taken its place in ALGE's literature by 2015.

See the [start-systems overview](index.md) for the shared background that applies to every start
system.
