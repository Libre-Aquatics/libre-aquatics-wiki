This article is a stub. The ORA2 is an Omega start system named among the swimming equipment
used at the 1984 Olympic Games, which FINA allowed Omega to call "FINA Approved" in 1985, and
it worked with the [OSM6](../timers/osm6.md) console.

See the [start-systems overview](index.md) for the shared background that applies to every
start system.
