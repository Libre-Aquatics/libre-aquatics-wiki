This article is a stub. BANG is the [ALGE-Timing](../../../vendors/alge-timing.md) speaker start
system series, and the 80 W `BANG2` gives the start signal in ALGE
[semi-automatic](../semi-automatic/index.md) swimming systems.

See the [start-systems overview](index.md) for the shared background that applies to every start
system.
