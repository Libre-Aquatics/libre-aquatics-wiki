This article is a stub. The `STB1` is the [ALGE-Timing](../../../vendors/alge-timing.md)
startbeep that ALGE's 2013 swimming catalogue shows giving the start tone for a
[Timy](../timers/alge-timy.md) semi-automatic system, a role the [BANG2](alge-bang.md) speaker
system fills in the 2026 catalogue.

See the [start-systems overview](index.md) for the shared background that applies to every start
system.
