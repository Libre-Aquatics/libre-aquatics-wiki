This article is a stub. The `SM8` is an [ALGE-Timing](../../../vendors/alge-timing.md) start
microphone that plugs into the [SU3](alge-su3.md) as an alternative to its start button.

See the [start-systems overview](index.md) for the shared background that applies to every start
system.
