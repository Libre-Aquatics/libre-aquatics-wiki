This article is a stub. The `SM6` is an [ALGE-Timing](../../../vendors/alge-timing.md) start
microphone that the [Timer S4](../timers/alge-timer-s4.md) manual shows sending a pistol-shot start
impulse to the timer through an SV3 speech amplifier, the arrangement later used by the
[SM8](alge-sm8.md).

See the [start-systems overview](index.md) for the shared background that applies to every start
system.
