This article is a stub. The `P5` is an [ALGE-Timing](../../../vendors/alge-timing.md) thermal
printer that prints each timing impulse as it arrives, used with the
[SWIM 2000](alge-swim-2000.md) system and later the [TM-SWIM](alge-tm-swim.md) before the
[P6-8](alge-p6-8.md) replaced it.

See the [timers overview](index.md) for the shared background that applies to every timing
console.
