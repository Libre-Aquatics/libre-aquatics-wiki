This article is a stub. The `WTN-WS` is an [ALGE-Timing](../../../vendors/alge-timing.md)
radio unit on the [WTN](alge-wtn.md) network that carries readings from a track-and-field wind
anemometer to a [Timy3](alge-timy.md) and display data back to the anemometer's board.

See the [timers overview](index.md) for the shared background on timing consoles.
