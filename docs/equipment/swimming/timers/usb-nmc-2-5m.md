This article is a stub. The `USB-NMC-2.5m` is a USB null modem cable from
[FTDI](../../../vendors/ftdi.md) that Superior Swim Timing has tested for the serial link between
the [SST timing software](../../../software/sst-timing-software.md) and a meet computer.

See the [timers overview](index.md) for the shared background on timing consoles.
