This article is a stub. The `BANG-HS` is an [ALGE-Timing](../../../vendors/alge-timing.md) radio
headset microphone that sends the starter's voice to the UHF receiver of a
[BANG](../starter/alge-bang.md) speaker, so commands can be given without a cable.

See the [timers overview](index.md) for the shared background that applies to every timing
console.
