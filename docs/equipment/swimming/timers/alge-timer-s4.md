This article is a stub. The Timer S4 is an [ALGE-Timing](../../../vendors/alge-timing.md) timer
described in a 1997 guide, which ran eight swimming lanes through an S4-SWIM lane box and one
FIN1 finish adapter for every two lanes.

See the [timers overview](index.md) for the shared background that applies to every timing
console.
