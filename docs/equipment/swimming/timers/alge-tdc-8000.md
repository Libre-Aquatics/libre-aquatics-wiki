This article is a stub. The `TdC 8000` is an [ALGE-Timing](../../../vendors/alge-timing.md) timing
computer with a built-in printer, housed in a briefcase, which can drive
[GAZ4](../../common/scoreboard/alge-gaz4.md) display boards over a two-wire data cable.

See the [timers overview](index.md) for the shared background that applies to every timing
console.
