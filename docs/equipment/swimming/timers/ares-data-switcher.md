This article is a stub. The ARES data switcher, part number `3330.701`, is an option for the
Swiss Timing [ARES 21](ares-21.md) system that its datasheets list without describing, and which
by comparison with [Quantum Aquatics](quantum.md) appears to select between a main and a backup
timer.

See the [timers overview](index.md) for the shared background that applies to every timing
console.
