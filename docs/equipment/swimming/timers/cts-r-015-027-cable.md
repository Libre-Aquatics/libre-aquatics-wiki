This article is a stub. The `R-015-027` cable runs from a Colorado Time Systems speedlight
[relay judging platform](../relay-judging/cts.md) to a cable harness, a connection hub or a
[DP-series deck plate](../deck-cabling/cts-dp-7-deck-plate.md), with a stackable banana plug that shares the button A jack and a
mini BNC leg for the start system's speedlight signal.

See the [deck cabling overview](../deck-cabling/index.md) for the shared background that applies to
every deck plate and harness.
