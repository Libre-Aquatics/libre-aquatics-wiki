This article is a stub. The DH-1 is the optional data handling module for the Omega
[OSM6](osm6.md) console, named in Hy-Tek's interface guide, which lets the console pass race
results and splits to a meet-management computer over its data handling socket.

See the [timers overview](index.md) for the shared background that applies to every timing
console.
