Timer S4 manual (E-06-04-18), pages 3 and 8-9: the NLG4 can go into any of the S4's DIN photocell
sockets, and one DIN socket is set aside for it. It runs the timer from 220 V or 110 V mains while
the internal cells stay in as a backup, and it recharges NiCd cells in about 14 hours. The manual
warns against using it when the timer is set for alkaline cells; a red or black mark in a hole on
the back of the case shows which cell type the timer is set for.
Swimming installation guide E-97-03-24, page 1: the S4 normally runs from a 12 V car battery or the
NLG4; the drawings show it on 220 V / 50 Hz.

This article is a stub. The `NLG4` is the [ALGE-Timing](../../../vendors/alge-timing.md) mains
charging set that runs a [Timer S4](alge-timer-s4.md) and recharges its NiCd cells, which then
serve as a backup supply.

See the [timers overview](index.md) for the shared background that applies to every timing
console.
