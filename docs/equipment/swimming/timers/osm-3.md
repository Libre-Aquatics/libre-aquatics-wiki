This article is a stub. The OSM-3 is an Omega swim timing system for permanent installations, in
which an operator console worked with a separate computer cabinet that printed every split and
finish, with relay take-off judging and multi-line display boards as part of the system.

It was sold beside the portable [OSM-4](osm-4.md) and [OSM-5](osm-5.md); see the
[timers overview](index.md) for the shared background.
