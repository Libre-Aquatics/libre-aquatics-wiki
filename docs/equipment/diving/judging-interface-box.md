This article is a stub. The judging interface box, called the Judging V interface box in the
System 5 documentation, is the Colorado Time Systems box with numbered jacks into which up to
ten wired [judging terminals](judging-terminals.md) plug, joined by one five-pin cable to the
Diving-Expansion I/O port of a [System 5](../swimming/timers/system-5.md) or the Judges I/O
port of a [System 6](../swimming/timers/system-6.md).

See the [diving equipment overview](index.md) for the shared background on judging equipment.
