Free tools for working with the files that competition software produces, built by this
wiki and run entirely in the reader's own browser. A file opened in one of them is not
uploaded, sent anywhere or kept.

## What lives here

The other sections of the wiki describe equipment, software and the formats that carry
data between them. This section holds working tools built on that research: each one
applies what a format article documents, such as record layouts, code tables and the
quirks of the programs that write the files, to a file the reader supplies.

Each tool has its own page explaining what it reads, what it checks and where its limits
are, with a link back to the article on the format it handles.

## Articles

- [SDIF file reader](sdif-reader.md): opens an [SDIF](../software/sdif.md) `.sd3` or Hy-Tek
  [CL2](../software/cl2.md) results file, or the `.zip` that Meet Manager exports, and shows
  the meet results, every record field by field, a check against the version 3
  specification, and CSV exports
